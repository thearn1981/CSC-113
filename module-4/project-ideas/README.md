# Project Ideation - Teresa Hearn

## Idea 1: AI Gym Workout Planner

**Problem/Goal:**
Many people lose track of their workouts or repeat the same muscle groups too often. This project would track exercises, sets, reps, and weight used in a database and use simple AI logic to generate a balanced workout plan for the next week.

**AI Tool(s):**
Python, simple rule-based AI logic, and possibly an AI API for recommendation improvements.

**Why This Interests Me:**
I recently started going to the gym, so this is a problem I personally experience. Building this would help me stay consistent and stay motivated having a plan.

**Rough Scope:**
2–3 week project.

## Idea 2: AI Budget House Planner / Tracker

**Problem/Goal:**
Many people struggle to track household spending and understand where their money is going. This project would store expenses in a database, categorize spending, and use AI to analyze patterns, predict future expenses, and provide budgeting insights.

**AI Tool(s):**
Python, data analysis libraries (such as pandas), and simple AI or rule-based pattern detection.

**Why This Interests Me:**
Managing finances is an important life skill, and creating a tool like this could help organize household spending reducing stress.

**Rough Scope:**
2–3 week project.

## Idea 3: AI Health Tracker

**Problem/Goal:**
Health data such as blood sugar and blood pressure readings are often recorded but not analyzed over time. This project would store health readings in a database and use AI to analyze trends and detect potential health changes.

**AI Tool(s):**
Python, basic AI trend analysis, and possibly visualization tools for tracking health data over time.

**Why This Interests Me:**
Health tracking is useful for understanding long-term patterns, and this project would allow me to explore how AI can assist in identifying trends in personal health data.

**Rough Scope:**
2–3 week project.
