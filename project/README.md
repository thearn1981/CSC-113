# 🏋️ Gym Workout Planner MVP

## What is this?
This is a beginner-friendly gym workout planner built as a single-page web app. The goal was to create something that removes the confusion people feel when starting at the gym by giving them a clear, step-by-step plan to follow.

## What does it do?
The app lets users set up their preferences (goal, workout days, style) and generates a 7-day workout plan. It shows exactly what to do each day (warm-up, strength, cardio, stretching) and allows users to log their workouts. Everything runs in the browser using localStorage — no accounts or backend required.

## How far did I get?
The core functionality is complete and working as a prototype. Users can generate plans, view daily workouts, and log sessions. Some features go beyond the original MVP (like multiple workout styles and dark mode), but overall it’s still a front-end prototype and not a full production app.

## What AI tools did I use?
- ChatGPT (planning, PRD, code generation, iteration)
- Other AI tools (tested for comparison, including different workout plan outputs)
